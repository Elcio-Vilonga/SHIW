# SHIW — Simple Password Manager



**SHIW** is a password manager developed in Java, designed to register, organize, and manage credentials through a Command-Line Interface (CLI).



This is a personal educational project, developed as part of my journey to learn Java and strengthen my understanding of Object-Oriented Programming (OOP).



###### **Features**



Currently, SHIW supports:



Register passwords: Add new credentials, including platform name, username, and password.



List passwords: Display all registered credentials.



View password details: Select and view a credential using its unique ID.



Edit credentials: Update the information of an existing credential.



Delete credentials: Remove credentials from the list.





###### **Technologies**

* Object-Oriented Programming (OOP)
