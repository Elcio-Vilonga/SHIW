FASE 7 — ABRIR PASSWORD
======================

Objetivo:
Selecionar uma Password e visualizar os seus detalhes.

FLUXO

Lista
  |
  v
Selecionar ID
  |
  v
Encontrar Password
  |
  v
Mostrar detalhes
  |
  +-- Editar
  +-- Remover
  +-- Voltar

EXEMPLO

========== GITHUB ==========

Username: meuUsuario
Password: abc123

1 - Editar
2 - Remover
3 - Voltar

CHECKLIST

- [✔️ ] Pedir o ID.
- [✔️ ] Procurar a Password.
- [✔️ ] Verificar se existe.
- [✔️ ] Mostrar os detalhes.
- [✔️ ] Criar submenu.
- [✔️ ] Implementar opção Editar.
- [✔️ ] Implementar opção Remover.
- [✔️ ] Implementar opção Voltar.

ERRO

Se o ID não existir:

Password não encontrada.

CONCLUÍDO QUANDO:

[✔️ ] Consigo abrir qualquer Password pelo ID.
[✔️ ] Consigo voltar sem alterar nada.
