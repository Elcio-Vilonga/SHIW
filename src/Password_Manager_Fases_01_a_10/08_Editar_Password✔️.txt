FASE 8 — EDITAR PASSWORD
=======================

Objetivo:
Alterar os dados de uma Password existente.

EXEMPLO

========== EDITAR ==========

Nome atual: GitHub
Novo nome:

Username atual: meuUsuario
Novo username:

Password atual: abc123
Nova password:

CHECKLIST

- [✔️ ] Encontrar a Password.
- [✔️ ] Mostrar dados atuais.
- [✔️ ] Permitir alterar nome.
- [✔️ ] Permitir alterar username.
- [✔️ ] Permitir alterar password.
- [✔️ ] Atualizar o objeto.
- [✔️ ] Mostrar confirmação.
- [✔️ ] Voltar ao menu.

DESAFIO

Permitir que o utilizador mantenha um campo sem alteração.

EXEMPLO:

Novo nome: [ENTER]

Nesse caso, manter o nome atual.

CONCLUÍDO QUANDO:

[✔️ ] Consigo editar os dados de uma Password.
[✔️ ] A alteração aparece quando abro novamente a entrada.
