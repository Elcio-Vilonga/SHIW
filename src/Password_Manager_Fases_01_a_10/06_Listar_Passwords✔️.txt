FASE 6 — LISTAR PASSWORDS
=========================

Objetivo:
Mostrar as Passwords registradas de forma organizada.

EXEMPLO

========== PASSWORDS ==========

1 - Gmail
2 - GitHub
3 - Facebook

0 - Voltar

IMPORTANTE

Nesta tela, não mostrar a password diretamente.

CHECKLIST

- [✔️ ] Criar opção Listar.
- [✔️ ] Percorrer o ArrayList.
- [✔️ ] Mostrar ID.
- [✔️ ] Mostrar nome.
- [✔️ ] Não mostrar a password.
- [✔️ ] Permitir voltar ao menu.
- [✔️ ] Tratar o caso de a lista estar vazia.

PRÁTICA

Se não houver nenhuma password:

Nenhuma password registrada.

CONCLUÍDO QUANDO:

[✔️ ] Consigo ver todas as entradas cadastradas.
[✔️ ] A password não aparece na listagem.
