# SHIW — Simple Password Manager



**SHIW** é um gestor de senhas desenvolvido em Java, com o objectivo de permitir o registo, a organização e a gestão de credenciais através de uma interface de linha de comandos (CLI).



Este é um projecto pessoal e educativo, desenvolvido como parte do meu processo de aprendizagem da linguagem Java e da programação orientada a objectos.



###### Funcionalidades



Actualmente, o SHIW permite:



\- **Registar senhas:** adicionar novas credenciais, incluindo o nome da plataforma, o nome de utilizador e a senha.

\- **Listar senhas:** visualizar os registos disponíveis.

\- **Consultar detalhes:** seleccionar uma credencial através do seu identificador (ID).

\- **Editar registos:** actualizar os dados de uma credencial existente.

\- **Remover registos:** eliminar credenciais da lista.



###### Tecnologias utilizadas



\- Java

\- Programação Orientada a Objectos (POO)

\- Java Collections Framework (`ArrayList` e `List`)

\- Manipulação de dados e métodos de classes



###### Objectivos de desenvolvimento



O SHIW está a ser desenvolvido por etapas, com o propósito de consolidar conhecimentos de programação e evoluir gradualmente para uma aplicação mais completa.



Alguns dos próximos objectivos são:



\- \[ ] Implementar a persistência de dados em ficheiros.

\- \[ ] Recuperar automaticamente os registos ao iniciar o programa.

\- \[ ] Implementar mecanismos de protecção e criptografia dos dados.

\- \[ ] Melhorar a validação de entradas e a experiência de utilização.

\- \[ ] Implementar um mecanismo de autenticação para proteger o acesso às credenciais.



###### Estado do projecto



**Em desenvolvimento.**



Novas funcionalidades e melhorias serão adicionadas progressivamente.



###### **Aviso**



Este projecto tem fins educativos e ainda não implementa mecanismos de segurança suficientes para proteger credenciais reais.



**Não utilizar para armazenar senhas pessoais ou informações sensíveis.**
